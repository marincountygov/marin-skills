# Accessibility Skills

> **Canonical requirements have moved.** The underlying accessibility *requirements* (what must be true — standard, WCAG 2.2 mapping, keyboard, focus, forms, color/contrast, documents, testing) now live in [marin-digital-standards/accessibility](https://github.com/marincountygov/marin-digital-standards/tree/main/accessibility). This repo still contains the full review workflow, severity model, and finding format below — that's staying here as active Skill content until it's refactored into a task-oriented `accessibility-review` Skill in a later migration phase. Until then, this content remains fully functional; nothing here is deprecated yet.

These skills support WCAG 2.2 AA alignment and accessible digital content production.

Use `core` for shared accessibility principles, review language, severity ratings, and cross-format requirements.

Use output-specific skills for production and review workflows:
- `web`: websites, web apps, HTML, CSS, JavaScript
- `office-documents`: DOCX, PPTX, spreadsheets, memos, reports, slide decks
- `pdf`: PDF export, review, remediation, and validation
- `social-media`: social posts, images, video captions, hashtags, and platform-specific accessibility
