# Content Design Skill

A reusable AI Skill for planning and classifying content — audience, intent, purpose, type, and placement — before it's written or restructured.

The underlying model (audience/intent categories, content-type definitions, page-purpose types, taxonomy principles) is canonical in [marin-digital-standards/content-design](https://github.com/marincountygov/marin-digital-standards/tree/main/content-design). This skill is the planning workflow that applies it.

## Files

- `SKILL.md` — workflow, standard brief output, decision rules, quality checklist.
- `subskills/audience-intent.md`
- `subskills/page-purpose.md`
- `subskills/content-types.md`
- `subskills/placement-and-metadata.md`

## Related skills

- `content-governance` — ownership, lifecycle, and editorial-calendar workflow once content is planned.
- `content-audit` — evaluating content that already exists.

## History

This skill is part of the split of `marinskills/content-strategy` into three task-oriented skills (`content-design`, `content-governance`, `content-audit`), per the marin-digital-standards migration plan. The general principles and content-type/purpose definitions moved to `marin-digital-standards/content-design`; the planning workflow that applies them became this skill.
