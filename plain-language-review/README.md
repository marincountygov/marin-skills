# Plain Language Review Skill

A reusable AI Skill for plain-language writing, rewriting, review, and web-content improvement.

The standard this skill applies is canonical in [marin-digital-standards/content-design](https://github.com/marincountygov/marin-digital-standards/tree/main/content-design) (`plain-language.md`, `voice-and-tone.md`, `terminology.md`). This skill is the workflow — output modes, quality checklist, preservation rules — not a second copy of the standard.

Source: GSA/plainlanguage.gov guidelines at https://github.com/GSA/plainlanguage.gov/tree/main/_pages/guidelines

## Files

- `SKILL.md` — the full workflow and routing instructions.

## History

This skill replaces `marinskills/plain-language` (a core `SKILL.md` plus five topic subskills: audience, organization, words-and-sentences, conversational-style, design-web-testing). Those subskills' content moved to `marin-digital-standards/content-design` as the canonical standard; this skill is the resulting task-oriented refactor.
