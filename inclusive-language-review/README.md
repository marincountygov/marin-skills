# Inclusive Language Review Skill

A reusable AI Skill for reviewing, rewriting, and advising on content using Marin's inclusive-language standard.

The standard this skill applies — disability, gender/family/identity, trauma-informed language, age/income, race/ethnicity/national origin, and public safety/health, each with escalation triggers — is canonical in [marin-digital-standards/content-design/inclusive-language.md](https://github.com/marincountygov/marin-digital-standards/blob/main/content-design/inclusive-language.md). This skill is the review/rewrite workflow, not a second copy of the standard.

## Files

- `SKILL.md` — the full workflow, output formats, and boundaries.

## History

This skill replaces `marinskills/inclusive-language-skill` (a core `SKILL.md` plus six category subskills). Those subskills' guidance moved to `marin-digital-standards/content-design/inclusive-language.md` as the canonical standard; this skill is the resulting task-oriented refactor — one skill, one entry point, no duplicated policy.
