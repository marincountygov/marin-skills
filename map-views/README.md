# Map Views Skill

A reusable AI Skill for adding and reviewing a map of point locations in a MarinOS app: location data, vendored Leaflet, markers, keyboard and screen reader behavior, the basemap, and the content security policy change.

The requirements this skill applies are canonical in [marin-digital-standards/product-design/maps.md](https://github.com/marincountygov/marin-digital-standards/blob/main/product-design/maps.md) and [marin-digital-standards/accessibility/maps.md](https://github.com/marincountygov/marin-digital-standards/blob/main/accessibility/maps.md).

## Files

- `SKILL.md` — the build workflow, the Leaflet gotchas, and the review checklist.

The working example is the Map view in [marin-reach](https://github.com/marincountygov/marin-reach).

Area maps (choropleths, service areas, boundaries) belong to `data-visualization-skill/data-visualization/subskills/maps-and-geospatial-content.md`.
