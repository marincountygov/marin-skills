# Social media

Posts, captions, alt text, hashtags, graphics, and video across social platforms. The underlying contrast and media requirements are the same ones in `marin-digital-standards/accessibility/color-and-contrast.md` and `standard.md` — this subskill covers platform-specific practice that doesn't map cleanly to a WCAG criterion but is still a real accessibility concern.

## Checks

- Alt text on every image the platform supports it for — see "Alt text" below.
- No image-of-text as the only source of information; repeat essential text from a graphic in the post body or a linked page.
- Captions on video (see `video-audio.md`).
- Hashtags in camelCase (`#MarinCounty`, not `#marincounty`) — screen readers announce camelCase hashtags as separate words instead of one unreadable string.
- Limited emoji use, and never as a substitute for a word a screen reader needs to announce meaningfully.
- No ASCII art or decorative typography that a screen reader will read literally.
- Sufficient contrast in graphics, and status/urgency never conveyed by color alone.
- A link to a fully accessible web page for anything that needs more than a short post can carry.

## Alt text guidance

Describe the image's purpose, not just its contents. Include any essential text shown in the image. Be concise but complete — omit purely decorative detail, and skip "image of"/"photo of" unless context requires it.

## Review workflow

1. Identify the primary message and audience.
2. Check caption clarity and reading level.
3. Review image alt text.
4. Check video captions and any audio/visual-only information.
5. Review hashtags, emoji, and graphics for the checks above.
6. Confirm the linked destination page is itself accessible and current.

## Output format

Use the standard finding format from `SKILL.md`.
