# Accessibility Review Skill

A reusable AI Skill for reviewing, testing, and remediating Marin digital content and products against Marin's accessibility requirements and WCAG 2.2 Level AA.

Requirements live in [marin-digital-standards/accessibility](https://github.com/marincountygov/marin-digital-standards/tree/main/accessibility). This skill is the review workflow that applies them — review posture, severity model, scope rules, and reporting format — not a second copy of the requirements.

## Files

- `SKILL.md` — core review methodology and routing instructions.
- `subskills/web.md` — websites, web applications, HTML/CSS/JS, components, testing.
- `subskills/documents.md` — PDF, Word, Excel, PowerPoint.
- `subskills/email.md` — newsletters, notices, alerts, transactional email.
- `subskills/forms.md` — any form, regardless of medium.
- `subskills/social-media.md` — posts, captions, alt text, hashtags, graphics.
- `subskills/video-audio.md` — video, audio, podcasts, livestreams.

## History

This skill consolidates what was previously `marinskills/accessibility` (a core skill plus eight medium-specific skills split across separate top-level folders). The requirements those files contained moved to `marin-digital-standards/accessibility` first; this skill is the resulting task-oriented refactor — one skill, one entry point, six focused subskills, no duplicated policy.
