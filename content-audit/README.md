# Content Audit Skill

A reusable AI Skill for evaluating existing content and recommending a disposition: keep, revise, merge, split, move, redirect, archive, or delete.

## Files

- `SKILL.md` — audit dimensions, recommendation labels, scoring model, output format.

## Related skills

- `content-design` — plan or reclassify content once an audit recommends revision.
- `content-governance` — assign lifecycle state and review cadence based on the audit outcome.

## History

Part of the split of `marinskills/content-strategy` into three task-oriented skills (`content-design`, `content-governance`, `content-audit`) per the marin-digital-standards migration plan. This skill is the audit/scoring workflow from the original content-strategy skill's `content-audit.md` subskill.
