# Marin Learn Content Skill

A reusable AI Skill for writing, building, and reviewing Marin Learn Notes, the decks built from them, and quizzes.

The standard this skill applies is canonical in [marin-digital-standards/content-design/learning-content.md](https://github.com/marincountygov/marin-digital-standards/blob/main/content-design/learning-content.md). The exact limits are enforced by `marin-learn` and written in its `docs/notes/SPEC.md`.

## Files

- `SKILL.md` — the workflow: a new Note, the deck, the quiz, a new course, and the review checklist.
